1. THE CORE PROJECT IDEA & MARKETING PHILOSOPHY
--------------------------------------------------------------------------------
The Elite Funnel Builder System is designed around a single core idea: "Traditional websites are conversion killers for high-value or experiential products." 

For custom furniture, luxury apartments, or signature dining spots, a standard e-commerce grid layout or multi-page corporate website creates decision fatigue. Window shoppers click around, get lost in menus, and drop off before taking action. 

This project solves that by replacing traditional browsing with highly structured, single-focus landing funnels that guide visitors through a curated decision pathway:
- Mobile-First & Kinetic: Over 85% of social ad traffic is mobile. The system uses fluid, responsive vertical containers, separation of concerns via clear stages, and active micro-animations to mimic native apps.
- The 3-Second Decision Hero: The very first screen presents a bold statement, key trust points, and a single call-to-action (e.g. "Menu" or "See Available Units") to establish intent immediately.
- Eliminating Form Friction: Instead of long registration forms, emails, and passwords, the platform captures the lead context (date, name, product interest) and instantly routes the user to a pre-filled WhatsApp conversation.
- Psychology-Driven Conversion Tactics:
  * Reciprocity: Showing signature items or floor plans first makes the buyer more likely to submit their details.
  * Scarcity & Urgency: Embedded status bars (e.g., "Tower 3 is almost sold out", "Weekend slots filling fast") nudge visitors to reserve immediately.
  * Social Proof: Built-in testimonials and rating badges directly support the buying decision close to CTAs.

Key Technology Stack:
- Core Framework: Next.js 15+ (App Router, Server Actions, Dynamic Routing)
- UI Library: React 19
- Styling: Tailwind CSS v4 (incorporating inline customized CSS variables)
- Animations: Framer Motion (for smooth micro-animations, transitions, and scroll indicators)
- Icons: Lucide React
- Backend/Database: Supabase (saves JSON templates, routes analytics, and persists leads)

3. THE ADMIN DASHBOARD FEATURES & CORE MODULES
--------------------------------------------------------------------------------
The dashboard is the central workstation for managing and customizing active funnels. It consists of the following key interfaces:

- Main Analytics Console:
  Shows total views, CTR (click-through rate), leads created, and a conversion graph.
- Lead Manager:
  Allows exporting lead files. Displays user submitted items like dates, names, party sizes, and selected pre-orders.
- Catalog Inventory Manager:
  Stores products in a master repository that can be assigned to different funnels.

The Editor Framework (Wizard Mode vs. Customizer Mode):
- Customizer Mode:
  Presents a full tabbed layout allowing instant access to all section panels (Branding, Showcase, Automation, Location).
- Wizard Mode:
  A guided checklist with descriptive instructions, pro tips, and placeholders to help new users set up their funnel step-by-step.
- Live Mobile Preview:
  A simulated mobile device on the right side of the screen displaying real-time updates as properties are modified in the editor sidebar.

Granular Editor Sections:
- BrandingPanel.tsx: Sets global accent colors, primary typography, brand slogans, and logo uploads.
- ShowcasePanel.tsx: Configures the main offerings (e.g. signature dishes for Cafe, apartments/suites for Real Estate, or furniture lines).
- WhatsAppPanel.tsx: Configures automated chat triggers, concierge options, welcome messages, and pre-filled inquiry text. Contains custom ref handles to prevent cursor jumping on state updates, and forces emoji system-font rendering fallback.
- LocationPanel.tsx: Manages addresses, opening hours, and embeds maps using parsed Google Map links.


4. THE THREE CLIENT-FACING CONVERSION TEMPLATES
--------------------------------------------------------------------------------

[A] ELITE CAFE & RESTAURANT TEMPLATE (EliteCafeTemplate.tsx)
Focuses on capturing table reservations and pre-orders.
- 3-Second Hero Header: Displays reservation triggers, tagline, and a prominent "Menu" button.
- Experience Center: An elegant photo scroller capturing the interior atmosphere of the café.
- Interactive Table Reservation Panel:
  * Visually beautiful Guest Count increment/decrement toggles.
  * Clock-style time selector showing hour and minute overlays.
  * Calendar selector for reserving slots.
- Menu Pre-Order Grid: Allows guests to browse categories (e.g. coffee, desserts) and add items directly to their WhatsApp message queue.
- WhatsApp Direct CTA: Formats the entire booking summary with dynamic replacements and opens a prefilled WhatsApp link. Special filters convert legacy emoji representations or database-corrupted characters directly into numbers.

[B] ELITE FURNITURE & RETAIL TEMPLATE (EliteFurnitureTemplate.tsx)
Optimized for premium product showrooms, catalog items, and retail creators.
- Image Hotspot Overlays: Places custom pulsing gold buttons on room photos. Clicking a dot opens a modal detailing the product.
- Scroll-Driven Sketch Story: A sequential transition section. Shows sketches/blueprints, raw materials, and finalized products as the user scrolls.
- Concierge Request Panel: Allows inputting custom wood finishes, sizing, or fabrics.

[C] ELITE REAL ESTATE TEMPLATE (EliteRealEstateTemplate.tsx)
Designed for builders, agents, and luxury property marketing.
- BHK Selectors: Simple toggles to switch between 2BHK, 3BHK, and 4BHK.
- Symmetrical Location Section: A beautifully aligned layout featuring a full-width header, and a side-by-side balanced grid displaying navigation details next to a Google Maps embed container.
- Interactive Floor Plan Viewer: Users click on rooms inside the blueprint to view specifications (e.g. Master Bedroom size, floor finish) instantly.


5. DATA FLOW & INTEGRATIONS
--------------------------------------------------------------------------------
- Supabase Integration:
  Funnels are read and written as JSON payloads in the database. The database records active values like page titles, images, and coordinates.
- Lead Capture Action:
  Before redirecting users to WhatsApp, the template triggers `createLead` which logs the visitor's intent, timestamp, and metadata in the dashboard database.
- Dynamic String Formatter:
  Replaces brackets (e.g. `{name}`, `{date}`, `{time}`, `{party_size}`) inside pre-configured templates with actual guest inputs.
- Safe Number Formatting:
  Converts characters like `👤`, `👥`, `📅`, and `🕒` (which often turn into `?` or `` in standard databases) into a clean numbered list (`1. Name:`, `2. Party Size:`, etc.) for seamless cross-platform communication.
