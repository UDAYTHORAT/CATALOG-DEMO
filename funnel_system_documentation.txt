# Funnel System Documentation

This document contains the complete code and explanation for the Public Funnel Runtime and the Dashboard Funnel Management system.

---

## 1. Public Funnel Runtime (`src/app/s/[slug]`)

This directory handles the public-facing view of a funnel. It uses a dynamic route `[slug]` to fetch funnel data from Supabase and render it using a high-conversion "Decision Engine" UI.

### how it works:
1. **Server Component (`page.tsx`)**: 
   - Resolves the `slug` from the URL.
   - Fetches the funnel data along with its associated store details.
   - Fetches the products linked to this specific funnel via a junction table `funnel_products`.
   - Passes the data to the client-side component.
2. **Client Component (`FunnelClient.tsx`)**:
   - Manages a two-step flow: `landing` (Hook) and `products` (Desire).
   - **Landing Step**: Displays a hero section with emotional hooks, trust signals, and categories.
   - **Products Step**: Dynamically filters and displays products based on the user's category selection.
   - **WhatsApp Integration**: When a user clicks a CTA, it tracks the lead (via `createLead` action) and redirects to WhatsApp with a pre-filled, personalized message.
   - **Theme Engine**: Applies custom colors (background, text, accent) defined in the funnel configuration.

### File: `src/app/s/[slug]/page.tsx`
```tsx
import { createClient } from '@/lib/supabase/server';
import { notFound } from 'next/navigation';
import FunnelClient, { type FunnelProduct } from './FunnelClient';

type FunnelProductJoin = {
  products: FunnelProduct | null;
};

export default async function PublicFunnelPage({ params }: { params: Promise<{ slug: string }> }) {
  const resolvedParams = await params;
  const slug = resolvedParams.slug;
  const supabase = await createClient();

  // 1. Fetch Funnel with Store details
  const { data: funnel } = await supabase
    .from('funnels')
    .select(`
      *,
      stores (
        id,
        name,
        bio,
        logo_url,
        whatsapp_number
      )
    `)
    .eq('slug', slug)
    .single();

  if (!funnel || !funnel.is_active) {
    notFound();
  }

  // 2. Fetch linked products via funnel_products junction
  const { data: funnelProducts } = await supabase
    .from('funnel_products')
    .select(`
      display_order,
      products (
        id,
        name,
        description,
        price,
        image_url,
        image_url_2,
        category,
        dimensions
      )
    `)
    .eq('funnel_id', funnel.id)
    .order('display_order', { ascending: true });

  const products = ((funnelProducts as any[] | null)?.map((fp) => fp.products).filter(Boolean) || []) as FunnelProduct[];

  return (
    <main className="min-h-screen">
      <FunnelClient 
        funnel={funnel} 
        store={funnel.stores} 
        products={products} 
      />
    </main>
  );
}
```

## 2. Dashboard Funnel Management (`src/app/(dashboard)/dashboard/funnels`)

This directory contains the admin interface for managing, creating, and editing funnels.

### how it works:
1. **List View (`page.tsx` & `FunnelsClient.tsx`)**:
   - Fetches all funnels and available products.
   - Provides a "Command Center" feel with stats (Total Leads, Conversion Rate).
   - Allows switching between Grid and List views.
   - Features a Search bar and "New Funnel" trigger.
   - Each funnel card displays its theme, lead count, and quick links (View, Edit, Analytics, Delete).
2. **Edit Flow (`[id]/edit/page.tsx` & `FunnelEditor.tsx`)**:
   - Fetches the specific funnel by `id`.
   - **FunnelEditor**: A multi-step builder (Landing, Products, WhatsApp + Theme).
   - Features a **Live Mobile Preview** that updates in real-time as the user edits text, categories, or colors.
   - Uses `AnimatePresence` for smooth step transitions.
   - Syncs changes back to Supabase via the `updateFunnel` server action.

import { createClient } from '@/lib/supabase/server';
import { notFound } from 'next/navigation';
import { getProducts } from '@/app/actions/products';
import FunnelEditor from './FunnelEditor';

export default async function EditFunnelPage({ params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();

  if (!user) {
    notFound();
  }

  const { data: funnel } = await supabase
    .from('funnels')
    .select('*, funnel_products(product_id)')
    .eq('id', id)
    .single();

  if (!funnel) {
    notFound();
  }

  const products = await getProducts();
  const linkedProductIds = funnel.funnel_products?.map((fp: any) => fp.product_id) || [];

      <FunnelEditor 
        funnel={funnel} 
        allProducts={products} 
        initialLinkedProductIds={linkedProductIds}

    </div>
  );
